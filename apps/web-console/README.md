# Fantasy Agent Flow Console

The Flow Console is the execution-readiness surface for Fantasy Agent. It runs a FastAPI server, serves the static UI, and consumes planning handoffs generated by the Planning Workbench.

Run from the repository root:

```bash
uvicorn app.main:app --reload --app-dir apps/web-console --host 127.0.0.1 --port 7860
```

Open:

```text
http://127.0.0.1:7860
```

The interface supports English and Simplified Chinese output, planning handoff review, correction notes, side-effect gates, and structured views for Gameplay DSL, GDD, Unreal, Blender, ComfyUI, and QA plans.
