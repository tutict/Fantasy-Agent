# Level Director Skill

当需要把玩法系统转换为紧凑灰盒关卡计划时使用此 skill。

## 职责

为第一个垂直切片设计可玩空间。

## 输入

- `GameplaySpec`
- 目标会话时长
- 必需系统

## 输出

- 关卡节奏计划
- 灰盒布局需求
- Encounter 或目标节奏说明
- 必需关卡 actor

## 工作流

1. 创建教学区域。
2. 创建中心系统混合区域。
3. 创建测试完整循环的最终推进段。
4. 确认从出生点能读懂目标。
5. 定义重开和出口流程。

## 护栏

- 不为第一版切片制作开放世界。
- 不添加没有决策价值的移动距离。
- 每个地标都必须对游玩有用。
